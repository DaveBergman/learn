# 1.0 Using Transforming Commands for Visualizations (5%)

## 1.1 The `chart` command

The `chart` command is a **transforming command** — it returns results in a
table format that can then be rendered as a chart (column, line, area, pie).

- You must specify at least one **statistical function** — one or more
  functions can be used in a single `chart` invocation, but only **one `BY`
  clause** is allowed.
- The function can apply to an SPL expression, a field, or set of fields;
  use `AS` to name the resulting field.
- The field named in the `BY` clause becomes the chart's x-axis (discretized
  if needed). This is the key contrast with `timechart` below: `chart`
  produces a table with an **arbitrary field** as the x-axis, not time.

Example (equivalent restated form of Splunk's docs example — counts of
cart-adds and purchases per product; the live doc page's original wraps
each conditional inline as `count(` + SPL's expression-evaluation function
+ `(action="addtocart"))` rather than pre-computing flag fields, but the
two forms produce the same result and this form is easier to read as a
worked example):
```
sourcetype=access_* status=200
| eval is_addtocart=if(action="addtocart",1,0)
| eval is_purchase=if(action="purchase",1,0)
| chart count AS views, sum(is_addtocart) AS addtocart, sum(is_purchase) AS purchases by productName
```

Source: [`chart` command reference](https://docs.splunk.com/Documentation/Splunk/latest/SearchReference/Chart), Splunk Enterprise/Cloud Platform docs — accessed 2026-07-18. ## 1.2 The `timechart` command

`timechart` creates a time series chart with a corresponding statistics
table — a statistical aggregation applied to a field, with **`_time`** fixed
as the x-axis (this is the defining difference from `chart`, which takes an
arbitrary `BY` field as its x-axis).

- Requires either a single aggregate function, or an SPL expression with a
  `BY` clause.
- If neither `bins` nor `span` is specified, `timechart` defaults to
  `bins=100`.
- Typical uses: "for each hour, count events by host value"; "for each
  minute, average CPU by host."

Source: [`timechart` command reference](https://docs.splunk.com/Documentation/Splunk/latest/SearchReference/Timechart), classic SPL (Splunk Enterprise/Cloud Platform) docs — accessed 2026-07-18. (Re-pointed from the SPL2/SCS reference during fact-check: Power User tests classic SPL; behavior is identical across both but the citation should match the tested syntax.)
