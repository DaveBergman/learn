# 4.0 Creating and Managing Fields (10%)

## 4.1 Perform regex field extractions using the Field Extractor (FX)

The **Field Extractor (FX)** is a GUI-based tool for creating field extractions
interactively. When you need to extract unstructured data (e.g., text from log
lines), regex extraction lets you match patterns and capture values into named
fields.

**Regex extraction workflow:**
1. Open the Field Extractor from Splunk's UI (Settings → Fields → Field
   Extractions, or via the Events view).
2. Select a sample event containing the data you want to extract.
3. Highlight the first value you want to capture.
4. FX generates a regex pattern; refine it as needed.
5. Test against multiple events to ensure correctness.
6. Save the extraction as a **field extraction** (stored in props.conf or
   transforms.conf).

**Key regex concepts in Splunk extractions:**
- **Capturing groups** — parentheses `()` capture the text you want; groups
  become field values.
- **Delimiters and lookarounds** — use `[^,]+` to match everything except a
  comma, or lookahead/lookbehind to anchor patterns.
- **Example:** From log line `user=alice action=login time=14:22`, extract
  the regex `user=(\w+)` to capture "alice" as the `user` field.

**FX stores extractions as:**
- `props.conf` (index-time extractions, applied during indexing).
- `transforms.conf` (search-time or index-time extractions, more flexible).

Source: [Splunk Field Extractor documentation](https://docs.splunk.com/Documentation/Splunk/latest/Knowledge/ExtractfieldsinteractivelyusingtheFX) — Splunk Enterprise/Cloud Platform docs. Accessed 2026-07-19.

## 4.2 Perform delimiter field extractions using the FX

When data is **structured with consistent delimiters** (comma-separated values,
space-separated, tab-delimited, etc.), delimiter extraction is simpler and more
efficient than regex.

**Delimiter extraction workflow:**
1. In the Field Extractor, select the sample event.
2. Choose **Delimiter** extraction mode (not Regex).
3. Specify the delimiter character(s): comma, space, tab, pipe, etc.
4. FX automatically splits the line and lets you name each field.
5. Test on multiple events.
6. Save the extraction.

**Example:** For CSV data like `alice,200,purchase,14.50`, specify the
delimiter as `,` and name the fields as `user`, `status_code`, `action`,
`amount`.

**When to use delimiter extraction:**
- Data is already well-structured with consistent delimiters.
- Regex is overkill for simple splitting.
- Performance: delimiter extraction is faster than regex.

**When regex is necessary:**
- Delimiters are inconsistent or context-dependent.
- You need pattern matching (e.g., match only 3-digit numbers).
- The data spans multiple lines or has nested structures.

Source: [Splunk Field Extractor documentation](https://docs.splunk.com/Documentation/Splunk/latest/Knowledge/ExtractfieldsinteractivelyusingtheFX) — Accessed 2026-07-19.
